Rules ground-truth (consolidated)

The full rule corpus across all five sources distills to three explicit constraints. There are no others.

# Rule Source Severity
R1 At least one submitted model must use ≥ 1 classification algorithm covered in the course. README.md (Classroom template), Session 20 slide, parsertongue final rubric HARD
R2 Code must be installable / runnable on Linux or macOS by another person. README.md (Classroom template) HARD
R3 Source code in the repo must be complete, runnable, and reproduce the Kaggle submissions. D2L rubric "Code minimum" PASS criterion HARD

The PA-specific rule "do not use any third-party libraries beyond what's in the autograded image" applies only to PA2/PA3/PA4 — it does not apply to the competition. The competition README.md explicitly states the opposite: "You are free to add dependencies."
